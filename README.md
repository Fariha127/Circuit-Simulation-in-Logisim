
# 🔷 Circuit Simulation in Logisim

This repository contains a collection of digital logic circuit designs and simulations created using **Logisim** — an educational tool for designing and simulating logic circuits.

## 🧠 About

As a CSE undergrad exploring **digital electronics** and **computer architecture**, I created this repository to simulate and better understand how logic gates and digital components come together to build complex systems like adders, multiplexers, decoders, and eventually a complete CPU.

## 🧰 Tools Used

* [**Logisim**](http://www.cburch.com/logisim/) — Open-source digital logic simulator

## 🧩 Topics & Circuits Included

* Basic logic gates (AND, OR, NOT, XOR)
* Combinational circuits:

  * Half Adder / Full Adder
  * Multiplexers / Demultiplexers
  * Encoders / Decoders    
* Sequential circuits:

  * Flip-flops (SR, D, JK)
  * Registers
  * Counters
* Arithmetic circuits

> 📁 `.circ` files are included and can be opened directly in Logisim.

## 🎯 Learning Outcomes

* Understand the fundamentals of digital logic
* Visualize how data flows through digital circuits
* Simulate behavior before moving to hardware implementation
